pycsamt.stratagem
=================

Post-acquisition tooling for AMT surveys collected with Geometrics/EMI
Stratagem hardware: raw 19-column QC, WinGLink EDI-directory loading, GPS
coordinate injection, static-shift/frequency/noise processing, and
export/rename.
