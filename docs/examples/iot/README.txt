.. _iot_gallery:

IoT field operations
--------------------

These examples show how the :mod:`pycsamt.iot` subpackage can describe
field devices, station telemetry, edge QC, synchronisation, power budgets,
and acquisition dashboards around real AMT/MT/CSAMT survey data. Everything
runs on bundled recordings or the built-in simulator — no hardware, broker,
or network connection is required. See the :doc:`IoT API reference
</api/iot>` for the full catalogue.
