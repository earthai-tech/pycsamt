.. _general_examples:

Examples
========

Runnable, fully rendered examples for the pyCSAMT tool families. Every
script on this page is executed while the documentation is built, so
each thumbnail, figure, and printed output stays in sync with the code.

Click a card to open the full example — narrative text, code, figures,
and downloadable ``.py`` / Jupyter notebook versions. Hover a card for
a short description.

For guided, end-to-end workflow walkthroughs see the
:doc:`tutorials </tutorials/index>`; for the complete API reference see
the :doc:`API docs </api/index>`.
