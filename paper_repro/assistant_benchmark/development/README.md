# Assistant Benchmark Status

This directory is generated by:

```powershell
python scripts\run_assistant_paper_benchmark.py --dev-suite-ok
```

Current status: development-only.

The bundled assistant suite currently has 47 records. The manuscript protocol
requires a frozen 240-request held-out benchmark before these values can be
reported as final paper results.

## How to Make the Results Reportable

1. Expand the JSONL benchmark to 240 records with the annotation schema in the
   supplement: `id`, `query`, `expected_intent`, `expected_workflow`,
   `expected_line`, `expected_symbols`, `must_not_contain`, relevance
   judgments, and adjudication notes.
2. Place the frozen suite in a release directory, for example
   `paper_repro/benchmark/v2.0.0/`.
3. Rebuild the RAG index from the exact source snapshot used in the paper.
   The development run warned that the current `.pycsamt_rag` index is stale.
4. Run the benchmark without `--dev-suite-ok`:

   ```powershell
   python scripts\run_assistant_paper_benchmark.py `
       --suite-dir paper_repro\benchmark\v2.0.0 `
       --out-dir cag-paper\new-version\results\assistant_benchmark
   ```

5. Include `results/assistant_benchmark/assistant_results_macros.tex` in
   `main-revised.tex` only after the script succeeds on exactly 240 records.
