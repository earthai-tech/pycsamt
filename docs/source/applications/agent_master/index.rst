Agent Master
============

Agent Master is the conversational application for pyCSAMT workflow guidance,
delegation, report help, and code-aware assistance. It complements the GUI and
web app by giving users a guided interface to agents and project context.

   :doc:`/user_guide/agents/orchestrator`
       How the orchestrating agent behind this app plans and runs
       multi-step workflows — the guide to the brain, while this section
       documents the app surface.
