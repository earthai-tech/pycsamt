pycsamt.ai.inversion
=====================

Supervised, physics-informed (PINN), and hybrid neural-network inverters for
1-D/2-D/3-D EM inversion, plus uncertainty calibration, static-shift/skew
reliability weighting for the DUHI hybrid AI-physics pathway, and
experiment/run configuration.
