.. _user_guide_processing:

Data processing
================

Processing in pyCSAMT spans scientific operations, repeatable pipelines, and
agent-assisted workflows. This landing page routes users into those guides
instead of duplicating their function catalogues:

* :doc:`../emtools/index` — inspect quality, remove noise, correct static
  shift, and analyse impedance, tensors, strike, dimensionality, and source
  effects.
* :doc:`../pipeline/index` — compose processing steps into configured,
  reproducible runs with manifests and inspectable outputs.
* :doc:`../agents/processing_agents` — use workflow agents for QC,
  correction, phase analysis, and coordinated processing tasks.
* :doc:`../site/index` — understand the station and ``Sites`` containers on
  which processing operations work.
