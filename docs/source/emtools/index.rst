EM Tools Gallery
=================

Narrative, runnable documentation for :mod:`pycsamt.emtools` — one page per
module, each ending in a worked example that is executed when these docs
are built. For the full auto-generated API reference (every module,
including ones not covered here yet), see :doc:`../api/emtools`.

.. note::

   This gallery is being built out module by module. Only :doc:`tf`,
   :doc:`anisotropy`, :doc:`csumt`, :doc:`diag`, :doc:`dimensionality`,
   :doc:`fieldzone`, :doc:`frequency`, :doc:`gradient_imaging`,
   :doc:`impedance`, and :doc:`inspect` are available today; the
   remaining ``emtools`` modules (``advanced``, ``lcurve``, ``plot``,
   ``qc``, ``remove_noise``, ``skew``, ``source_array``,
   ``source_effects``, ``spectra``, ``ss``, ``strike``, ``tensor``)
   follow the same pattern.
